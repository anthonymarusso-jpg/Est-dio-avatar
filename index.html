Chave Fish Audio (somente acesso direto, opcional)

Pegue a chave no site do Fish Audio, no menu de API Keys. O ID da voz é o código que aparece no endereço da página da voz. A API tem cobrança própria para modelos pagos. O modelo S2.1 grátis é adequado para testes, conforme as condições vigentes da Fish Audio.

Conexão GitHub — buscar vozes e gerar áudio aqui

O GitHub Actions acessa o Fish Audio usando uma chave guardada como Secret. Assim, você escolhe vozes e gera áudio dentro deste app sem expor a chave Fish.

  1. No GitHub, abra seu repositório Avatar-studio → Settings → Secrets and variables → Actions → New repository secret.
  2. Nomeie o Secret FISH_AUDIO_API_KEY e cole sua chave de fish.audio/app/api-keys. Não escreva a chave aqui no chat.
  3. Crie um token GitHub fine-grained para apenas o repositório Avatar-studio com Contents: Read and write. Cole o token no campo abaixo.
  4. Toque em Testar conexão. Em seguida, busque a voz pelo nome e toque em Gerar voz aqui.
Configurar Secret no GitHubCriar token GitHub

Com o token preenchido, Buscas, Minhas vozes e Gerar voz usam automaticamente o GitHub. O token não fica salvo permanentemente no aparelho. O processamento pode levar algum tempo.

Boca falante (grátis, no aparelho)

O app pega o rosto do avatar e mexe a boca e o queixo no ritmo da voz. É mais simples que o DreamFace, mas não custa nada. Funciona melhor com o avatar de frente e de boca fechada.

DreamAPI (pago, mais realista)

A DreamAPI (do DreamFace) junta o vídeo do passo 1 com a voz nova e sincroniza a boca. Custa cerca de US$ 0,0075 por segundo de vídeo, cobrado do saldo da sua conta DreamAPI.
